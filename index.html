Learn Virtual Memory

Understand the basic concepts of Virtual Memory and Paging before using the simulator.

1. What is Virtual Memory?

Virtual Memory is a memory management technique that allows a computer to use secondary storage as an extension of main memory (RAM).

It gives each process its own virtual address space. The operating system manages how virtual addresses are mapped to physical memory.

Example:

A program uses virtual addresses without needing to know the exact physical RAM location where its data is stored.

2. What is Paging?

Paging is a memory management technique in which virtual memory is divided into fixed-size blocks called Pages, while physical memory is divided into blocks called Frames.

Pages and frames have the same size. The operating system uses a Page Table to map virtual pages to physical frames.

Example:

If page size is 16 bytes, each virtual page contains 16 bytes and each physical frame also stores 16 bytes.

3. Pages and Frames

Page: A fixed-size block of virtual memory.

Frame: A fixed-size block of physical RAM where a page can be stored.

A page can be loaded into any available physical frame. The Page Table keeps track of this mapping.

In this simulator:

  • Page Size = 16 bytes
  • Virtual Pages = 16
  • Physical Frames = 8
  • Total Virtual Address Range = 0 to 255
  • Total Physical RAM = 128 bytes

4. What is a Page Table?

A Page Table is a data structure maintained by the operating system. It stores the mapping between virtual pages and physical memory frames.

When a program accesses a virtual address, the system checks the Page Table to find the corresponding physical frame.

Example:

  • Virtual Page 0 → Frame 2
  • Virtual Page 1 → Frame 4
  • Virtual Page 2 → Frame 5

If a page is not currently loaded into RAM, its Page Table entry is marked as not present.

5. Virtual Address and Physical Address

Virtual Address: The address generated by the CPU for a process.

Physical Address: The actual location in physical RAM.

The virtual address is divided into two parts:

  • Virtual Page Number (VPN): Identifies the virtual page.
  • Offset: Identifies the exact byte position inside that page.

Address Translation Formulas:

VPN = Floor (Virtual Address / Page Size)

Offset = Virtual Address % Page Size

Physical Address = (Frame Number × Page Size) + Offset

Practical Example:

Suppose the Virtual Address is 37 and Page Size is 16 bytes.

  • VPN = Floor (37 / 16) = 2
  • Offset = 37 % 16 = 5
  • Page 2 is stored in Frame 5.
  • Physical Address = (5 × 16) + 5 = 85

Therefore, Virtual Address 37 is translated into Physical Address 85.

6. What is a Page Fault?

A Page Fault occurs when a program tries to access a virtual page that is not currently present in physical RAM.

The operating system handles the page fault and arranges for the required page to be loaded into physical memory.

Example from this simulator:

  • Virtual Address = 55
  • VPN = Floor (55 / 16) = 3
  • Offset = 55 % 16 = 7
  • Virtual Page 3 is initially not present in RAM.

Therefore, a Page Fault is detected. After loading Page 3 into Frame 2:

Physical Address = (2 × 16) + 7 = 39

7. FIFO Page Replacement Algorithm

FIFO stands for First In, First Out. It is a page replacement algorithm used when physical memory has no free frame for a required page.

FIFO replaces the page that entered memory first. It follows the order in which pages were loaded into RAM.

Example:

Suppose all physical frames are occupied and a new page needs to be loaded. FIFO selects the oldest loaded page for replacement.

In this simulator, FIFO is used to select a page for replacement when RAM is full.
